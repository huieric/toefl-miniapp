## 一、项目概述

**托福备考助手**是一款面向托福考生的智能刷题工具。核心模式：用户导入PDF → AI解析题目 → 在线刷题 → 错题自动入库 → FSRS 科学排程复习。

### 1.1 技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端（Web） | Vue 3 + Vite + Element Plus | 响应式，PWA 支持，**深色模式** |
| 管理后台 | Vue 3 + ECharts + Element Plus | 数据看板 + 用户/题目管理 |
| 后端 | Node.js + Express + JWT | **30+ 路由模块**，RESTful API |
| 数据库 | PostgreSQL (端口5433) | **22+张表**，FSRS 17个参数 |
| AI能力 | DeepSeek/OpenAI兼容 | PDF解析、口语写作打分、阅读标注、错题分析 |
| 图表 | ECharts 5.6.0 | 错题本AI分析可视化 + 周报图表 + **技能雷达图** + **等级对比图** |
| 部署 | Vite build + 后端 dev | 前端已构建 dist/ 产物 |

## 三、v26.0 新增功能详细设计

### 3.1 📅 GitHub 风格学习热力图

**竞品来源**：GitHub 贡献日历（Contribution Graph）

**核心功能**：
1. **5级热力图**：
   | 等级 | 分钟 | 颜色 | 含义 |
   |------|------|------|------|
   | Level 0 | 0 | #ebedf0 | 未学习 |
   | Level 1 | 1-20 | #9be9a8 | 轻度学习 |
   | Level 2 | 21-60 | #40c463 | 中度学习 |
   | Level 3 | 61-120 | #30a14e | 积极学习 |
   | Level 4 | 120+ | #216e39 | 大量学习 |
2. **统计信息**：总学习分钟、学习天数、最长连续、日均学习
3. **最近7天**：进度条可视化
4. **周视图**：按周聚合详细数据
5. **悬浮提示**：鼠标悬停显示详细数据

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/study-heatmap` | GET | 获取热力图数据（365天） |
| `/api/study-heatmap/week` | GET | 获取周视图详细数据 |

**前端组件**：`StudyHeatmap.vue`（GitHub风格日历 + 统计卡片 + 最近7天）+ Dashboard 入口卡片

### 3.2 ✍️ Grammarly 式语法检查（内嵌规则引擎）

**竞品来源**：Grammarly 实时语法检查

**核心功能**：
1. **10+内置语法规则**：
   | 类型 | 规则示例 | 严重程度 |
   |------|---------|---------|
   | 动词 | he/she/it + am/are | 🔴 高 |
   | 冠词 | a + 元音开头 | 🟡 中 |
   | 主谓一致 | he/she/it + 动词原形 | 🔴 高 |
   | 拼写 | dont/cant/wont 等 | 🟢 低 |
   | 重复 | 重复单词检测 | 🟢 低 |
2. **综合评分**：基于错误数量和类型（0-100分）
3. **错误高亮**：错误文本删除线 + 建议绿色高亮
4. **类型统计**：按错误类型分组统计
5. **改进建议**：根据错误类型生成针对性建议
6. **检查历史**：最近30次检查结果

**数据库**：
- `grammar_checks` 表：user_id, question_id, text, score, issue_count, issues_json

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/grammar-check` | POST | 检查文本语法 |
| `/api/grammar-check/history` | GET | 检查历史 |

**前端组件**：`GrammarAssistant.vue`（输入框 + 评分圈 + 错误列表 + 类型统计 + 历史）+ Dashboard 入口卡片

### 3.3 🌳 Forest 式专注会话时间线

**竞品来源**：Forest 专注森林（会话历史 + 树种升级）

**核心功能**：
1. **树种升级系统**：
   | 等级 | 名称 | 图标 | 所需会话 |
   |------|------|------|---------|
   | 0 | 幼苗 | 🌱 | 0 |
   | 1 | 小树苗 | 🌿 | 10 |
   | 2 | 树苗 | 🌲 | 30 |
   | 3 | 大树 | 🌳 | 60 |
   | 4 | 古树 | 🎄 | 120 |
   | 5 | 魔法树 | ✨ | 200 |
   | 6 | 黄金树 | 🌟 | 500 |
2. **会话时间线**：按时间倒序排列，带完成状态标记
3. **本周统计**：会话数 + 分钟数
4. **7天趋势**：柱状图可视化
5. **树种进度**：进度条显示下一级所需会话

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/focus-session/timeline` | GET | 会话时间线 + 统计 |
| `/api/focus-session/stats` | GET | 统计汇总 |
| `/api/focus-session/trees` | GET | 树种解锁信息 |

**前端组件**：`FocusSession.vue`（树种卡片 + 统计网格 + 趋势图 + 时间线）+ Dashboard 入口卡片
