## 一、项目现状总结

### 1.1 产品定位

**托福备考助手** 是一款面向托福考生的智能刷题工具。核心模式是：用户导入自己的学习资料（PDF），系统自动解析题目，用户在线刷题 → 答错自动进错题本 → FSRS 科学排程复习。

### 1.2 技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端（Web） | Vue 3 + Vite + Element Plus | 响应式，移动端 TabBar 适配 |
| 小程序 | 微信小程序原生 (WXML/WXSS/JS) | 骨架完成，内容待填充 |
| 管理后台 | Vue 3 + ECharts + Element Plus | 数据看板 + 用户/题目管理 |
| 后端 | Node.js + Express + JWT | 12 个路由模块，RESTful API |
| 数据库 | PostgreSQL (Docker) | 16 张表，17 个 FSRS 参数 |
| 部署 | Render.com + GitHub Pages | 免费方案，有冷启动延迟 |

## 四、核心功能详细需求

### 4.1 核心闭环：刷题 → 错题 → 复习

#### 流程描述

```
[上传 PDF] → [AI 解析题目] → [选择篇章] → [开始做题]
                                                ↓
                                          [提交答案]
                                                ↓
                                    ┌───────────┴───────────┐
                                    ▼                       ▼
                              [答对]                [答错 → 自动入库]
                                   ↓                         ↓
                             [看解析]               [加入错题本]
                                   ↓                         ↓
                              [继续下一题]           [FSRS 排程]
                                                       ↓
                                              [到达复习时间 → 提醒]
                                                       ↓
                                              [进入错题复习模式]
                                                       ↓
                              ┌──────────────────────────┼──────────────────┐
                              ▼                          ▼                  ▼
                         [Again ≤4min]            [Hard 2.5×]        [Good 1×]        [Easy 1.5×]
                              ▼                          ▼                  ▼
                         [S→0, 重新排程]       [S×0.5, D+0.5]    [S×1.3, D不变]    [S×1.5, D-0.5]
```

#### 功能需求

| 编号 | 功能 | 详细描述 | 验收标准 |
|------|------|---------|---------|
| CR-01 | 题目展示 | 展示 passage_text + 单题 + 4 选项 | 阅读流畅、选项可点击、当前选项高亮 |
| CR-02 | 答案提交 | 单选：点击即提交；多选：确认提交 | 提交后显示正确/错误反馈 |
| CR-03 | 结果展示 | 正确答案 + 解析 + 用时 | 正确率实时更新 |
| CR-04 | 错题入库 | 答错自动加入 wrong_questions | 去重（user_id + question_id 唯一） |
| CR-05 | FSRS 排程 | 使用 FSRS-4.5 计算 next_review_at | stability/difficulty 正确计算 |
| CR-06 | 复习提醒 | 仪表盘显示「N 道错题待复习」 | 到达复习时间立即展示 |
| CR-07 | 卡片复习 | 正面题目 → 点击翻转 → 四档评分 | 类似 Anki 体验 |

### 4.3 上传 PDF 体验

#### 流程

```
用户点击「上传题目」
        ↓
选择 PDF 文件
        ↓
后端接收 → 立即返回 uploadId
        ↓
前端开始轮询上传状态 (5s 间隔)
        ↓
后台 AI 解析 → 逐步入库
        ↓
每解析出 1 篇 → 前端刷新列表 → 显示新篇章
        ↓
全部解析完成 → 提示「解析完成：共 X 题 Y 篇」
```

#### 功能需求

| 编号 | 功能 | 详细描述 | 验收标准 |
|------|------|---------|---------|
| UP-01 | 文件选择 | 支持拖拽 + 点击上传，限制 PDF | 文件大小 ≤ 50MB |
| UP-02 | 上传反馈 | 立即返回 uploadId，告知「正在解析」 | 上传 1s 内响应 |
| UP-03 | 实时进度 | 轮询显示已解析篇数 | 每解析 1 篇更新展示 |
| UP-04 | 边解析边用 | 已解析的篇章立即可刷题 | 无需等全部完成 |
| UP-05 | 完成通知 | 解析完成弹窗 + 列表自动刷新 | 用户明确感知结果 |
| UP-06 | 失败处理 | 解析失败显示原因 + 重试按钮 | 不静默失败 |

## 八、风险 & 应对

| 风险 | 影响 | 应对 |
