## 一、项目概述

**托福备考助手**是一款面向托福考生的智能刷题工具。核心模式：用户导入PDF → AI解析题目 → 在线刷题 → 错题自动入库 → FSRS 科学排程复习。

### 1.1 技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端（Web） | Vue 3 + Vite + Element Plus | 响应式，PWA 支持，**深色模式** |
| 管理后台 | Vue 3 + ECharts + Element Plus | 数据看板 + 用户/题目管理 |
| 后端 | Node.js + Express + JWT | **36+ 路由模块**，RESTful API |
| 数据库 | PostgreSQL (端口5433) | **24+张表**，FSRS 17个参数 |
| AI能力 | DeepSeek/OpenAI兼容 | PDF解析、口语写作打分、阅读标注、错题分析 |
| 图表 | ECharts 5.6.0 | 错题本AI分析可视化 + 周报图表 + **技能雷达图** + **等级对比图** |
| 部署 | Vite build + 后端 dev | 前端已构建 dist/ 产物 |

## 三、v28.0 新增功能详细设计

### 3.1 🏆 Duolingo League (联赛系统)

**竞品来源**：Duolingo League（Duolingo 联赛）

**核心功能**：
1. **6 级段位系统**：
   | 段位 | 图标 | 最低 XP | 颜色 |
   |------|------|---------|------|
   | 青铜联赛 | 🥉 | 0 | #CD7F32 |
   | 白银联赛 | 🥈 | 500 | #C0C0C0 |
   | 黄金联赛 | 🥇 | 1500 | #FFD700 |
   | 铂金联赛 | 💎 | 3000 | #B9F2FF |
   | 钻石联赛 | 💠 | 6000 | #B9F2FF |
   | 大师联赛 | 👑 | 10000 | #FF6B6B |
2. **周赛排名**：每周日重置，XP 累计计算
3. **升级/降级机制**：根据 XP 自动升降级
4. **联赛成就**：6 种联赛相关成就（初登赛场、连胜勇士、段位晋升等）
5. **排行榜**：分页显示，支持段位筛选
6. **相对排名**：显示前后排名及 XP 差距

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/league` | GET | 获取段位配置 |
| `/api/league/leaderboard` | GET | 排行榜（分页+筛选） |
| `/api/league/user/:userId` | GET | 用户联赛信息 |
| `/api/league/add-xp` | POST | 添加 XP |
| `/api/league/achievements` | GET | 联赛成就列表 |
| `/api/league/ranks/:userId` | GET | 相对排名 |

**前端组件**：`League.vue`（段位展示 + 排行榜表格 + 成就列表 + 下周预测 + 重置倒计时）

### 3.2 📚 Enhanced SRS Review (间隔重复复习)

**竞品来源**：Mochi + Anki（间隔重复系统）

**核心功能**：
1. **智能复习调度**：基于艾宾浩斯遗忘曲线计算下次复习时间
2. **4 档评分系统**：
   - 😣 再次：<1 分钟重看
   - 😕 困难：1.2x 间隔
   - 😊 良好：2.5x 间隔
   - 😄 简单：4x 间隔
3. **记忆卡片翻转**：3D 翻转动画，正面显示单词，背面显示释义
4. **复习进度追踪**：今日目标进度条、已掌握/学习中统计
5. **记忆保留率**：基于正确/错误次数计算
6. **7 日趋势图**：柱状图显示每日复习量
7. **复习计划表**：本周每日复习计划 + 预计时间

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/srs-review` | GET | 获取 SRS 配置 |
| `/api/srs-review/due` | GET | 待复习卡片列表 |
| `/api/srs-review/review` | POST | 提交复习评分 |
| `/api/srs-review/stats` | GET | 复习统计 |
| `/api/srs-review/card/:id` | GET | 卡片详情 |
| `/api/srs-review/progress` | GET | 学习进度 |
| `/api/srs-review/schedule` | GET | 复习计划 |

**前端组件**：`SRSReview.vue`（概览卡片 + 进度条 + 翻转复习卡片 + 评分按钮 + 7 日趋势 + 复习计划）

### 3.3 🎯 Magoosh Score Predictor (托福分数预测)

**竞品来源**：Magoosh TOEFL Score Predictor

**核心功能**：
1. **四科分数预测**：
   - 阅读/听力：基于原始分转换 (0-30)
   - 口语/写作：基于 AI 评分推算
   - 总分：四科求和
2. **进步趋势图**：ECharts 折线图显示 7 周趋势
3. **提分建议**：按优先级排序（高/中/低），含目标练习建议
4. **模拟考试预测**：输入模拟考试成绩，预测 TOEFL 分数
5. **目标分数追踪**：设置目标分数，显示进度条和差距

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/score-predictor` | GET | 预测分数概览 |
| `/api/score-predictor/sections` | GET | 四科详细分析 |
| `/api/score-predictor/trend` | GET | 趋势数据 |
| `/api/score-predictor/recommendations` | GET | 提分建议 |
| `/api/score-predictor/mock-exam-prediction` | GET | 模拟考试预测 |
| `/api/score-predictor/set-goal` | POST | 设置目标分数 |

**前端组件**：`ScorePredictor.vue`（总分展示 + 四科卡片 + 趋势折线图 + 提分建议 + 模拟考试 + 目标追踪）
