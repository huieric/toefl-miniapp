## 一、项目概述

**托福备考助手**是一款面向托福考生的智能刷题工具。核心模式：用户导入PDF → AI解析题目 → 在线刷题 → 错题自动入库 → FSRS 科学排程复习。

### 1.1 技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端（Web） | Vue 3 + Vite + Element Plus | 响应式，PWA 支持，**深色模式** |
| 管理后台 | Vue 3 + ECharts + Element Plus | 数据看板 + 用户/题目管理 |
| 后端 | Node.js + Express + JWT | **33+ 路由模块**，RESTful API |
| 数据库 | PostgreSQL (端口5433) | **24+张表**，FSRS 17个参数 |
| AI能力 | DeepSeek/OpenAI兼容 | PDF解析、口语写作打分、阅读标注、错题分析 |
| 图表 | ECharts 5.6.0 | 错题本AI分析可视化 + 周报图表 + **技能雷达图** + **等级对比图** |
| 部署 | Vite build + 后端 dev | 前端已构建 dist/ 产物 |

## 三、v27.0 新增功能详细设计

### 3.1 🗣️ ELSA Speak 风格音素教练

**竞品来源**：ELSA Speak（AI发音教练）

**核心功能**：
1. **50+ 音素数据库**：涵盖20个元音+30个辅音，含托福高频难词映射
2. **难度分级**：难点音素（TH音对、长短元音对比）、中等难度、基础音素
3. **可视化评分**：环形评分图 + 音素卡片（问题/优秀分类）
4. **全部音素列表**：按得分排序，颜色编码（绿>80/橙60-80/红<60）
5. **个性化建议**：基于薄弱音素生成针对性练习建议
6. **进步趋势**：历史评分趋势图表

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/phoneme-score/score` | POST | 发音评分分析 |
| `/api/phoneme-score/history` | GET | 评分历史 |
| `/api/phoneme-score/trend` | GET | 进步趋势 |
| `/api/phoneme-score/problems` | GET | 问题音素分析 |

**前端组件**：`PhonemeCoach.vue`（输入框 + 环形评分 + 问题/优秀音素卡片 + 全部列表 + 趋势图 + 推荐难词）

### 3.2 📖 速度阅读训练

**竞品来源**：Speedreading.com + 墨墨背单词（阅读速度追踪）

**核心功能**：
1. **WPM 计量器**：SVG 环形仪表盘，实时显示当前阅读速度
2. **4 科目追踪**：阅读/听力/写作/口语 WPM 分别追踪
3. **5 级阅读等级**：
   | 等级 | 名称 | WPM范围 | 图标 |
   |------|------|---------|------|
   | 1 | 慢速阅读 | 0-150 | 🐢 |
   | 2 | 普通阅读 | 151-250 | 🚶 |
   | 3 | 快速阅读 | 251-350 | 🏃 |
   | 4 | 超快阅读 | 351-500 | 🚀 |
   | 5 | 专家级 | 501+ | 👑 |
4. **综合效率分**：WPM效率 × 0.5 + 理解率 × 0.5
5. **科目对比**：四科 WPM 环形卡片对比
6. **升级进度**：下一级 WPM 目标 + 进度条

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/speed-reading/start` | POST | 开始阅读训练 |
| `/api/speed-reading/complete` | POST | 完成并提交 |
| `/api/speed-reading/stats` | GET | 统计汇总 |
| `/api/speed-reading/history` | GET | 训练历史 |
| `/api/speed-reading/trend` | GET | 趋势追踪 |
| `/api/speed-reading/levels` | GET | 等级评估 |

**前端组件**：`SpeedReading.vue`（等级卡片 + WPM 仪表盘 + 四科统计 + 等级体系 + 训练表单 + 历史记录表格）

### 3.3 ⭐ 题目收藏系统

**竞品来源**：Quizlet 收藏夹 + Anki 标记

**核心功能**：
1. **收藏/取消收藏**：一键收藏/取消收藏题目
2. **备注编辑**：为收藏题目添加个人备注
3. **收藏统计**：按科目统计收藏数量
4. **筛选和搜索**：按类型筛选，搜索备注内容
5. **分页加载**：批量加载收藏列表
6. **批量移除**：批量取消收藏

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/bookmarks` | POST/GET | 添加/获取收藏列表 |
| `/api/bookmarks/:id` | DELETE/PUT | 取消收藏/更新备注 |
| `/api/bookmarks/stats` | GET | 收藏统计 |
| `/api/bookmarks/batch-remove` | POST | 批量移除 |

**前端组件**：
- `BookmarkList.vue`（收藏管理页面）
- 各题目详情页（ReadingDetail/SpeakingDetail/WritingDetail/ListeningDetail）添加收藏按钮
