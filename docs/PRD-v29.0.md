## 一、项目概述

**托福备考助手**是一款面向托福考生的智能刷题工具。核心模式：用户导入PDF → AI解析题目 → 在线刷题 → 错题自动入库 → FSRS 科学排程复习。

### 1.1 技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端（Web） | Vue 3 + Vite + Element Plus | 响应式，PWA 支持，**深色模式** |
| 管理后台 | Vue 3 + ECharts + Element Plus | 数据看板 + 用户/题目管理 |
| 后端 | Node.js + Express + JWT | **39+ 路由模块**，RESTful API |
| 数据库 | PostgreSQL (端口5433) | **27+张表**，FSRS 17个参数 |
| AI能力 | DeepSeek/OpenAI兼容 | PDF解析、口语写作打分、阅读标注、错题分析 |
| 图表 | ECharts 5.6.0 | 错题本AI分析可视化 + 周报图表 + **技能雷达图** + **等级对比图** |
| 部署 | Vite build + 后端 dev | 前端已构建 dist/ 产物 |

## 三、v29.0 新增功能详细设计

### 3.1 📝 Full Mock Exam (全真模拟考试)

**竞品来源**：Magoosh TOEFL Practice Tests

**核心功能**：
1. **全真模拟环境**：还原真实托福考试，计时无提示
2. **四科完整套题**：
   | 科目 | 时长 | 题目数 | 分数范围 |
   |------|------|--------|---------|
   | 阅读 | 60分钟 | 3篇 | 0-30 |
   | 听力 | 60分钟 | 2篇 | 0-30 |
   | 口语 | 20分钟 | 4题 | 0-30 |
   | 写作 | 50分钟 | 2题 | 0-30 |
3. **专项模考**：阅读/听力/口语/写作单科训练
4. **自动评分**：基于正确率和用时自动评分
5. **成绩历史**：完整记录所有考试，支持对比
6. **考试统计**：总分、平均分、最高分、分数分布

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/mock-exam` | GET | 模拟考试列表 |
| `/api/mock-exam/:examId` | GET | 考试详情 |
| `/api/mock-exam/start` | POST | 开始考试 |
| `/api/mock-exam/session/:id` | GET | 会话状态 |
| `/api/mock-exam/section/complete` | POST | 完成科目 |
| `/api/mock-exam/submit` | POST | 提交考试 |
| `/api/mock-exam/history` | GET | 历史记录 |
| `/api/mock-exam/stats` | GET | 考试统计 |
| `/api/mock-exam/templates` | GET | 考试模板 |

**前端组件**：`MockExam.vue`（模考列表+考试界面+成绩历史+评分结果）

### 3.2 🗺️ Learning Path (学习路径规划)

**竞品来源**：Khan Academy Skill Tree

**核心功能**：
1. **技能树可视化**：
   - 阅读：8个技能（主旨题、细节题、推理题、词汇题、句子简化、句子插入、摘要题、填空题）
   - 听力：5个技能（主旨理解、细节捕捉、笔记技巧、推断能力、分类题）
   - 口语：4个技能（独立表达、综合口语、流利度、发音）
   - 写作：4个技能（综合写作、独立写作、结构组织、语法词汇）
2. **6级掌握度**：入门→初级→中级→中高级→高级→精通
3. **前置技能依赖**：技能解锁机制，必须完成前置技能
4. **个性化推荐**：基于当前进度推荐下一步学习
5. **学习路径模板**：
   | 模板 | 时长 | 每日时间 | 难度 |
   |------|------|---------|------|
   | 30天冲刺 | 30天 | 3小时 | 高强度 |
   | 60天稳步 | 60天 | 2小时 | 中等 |
   | 90天全面 | 90天 | 1.5小时 | 轻松 |

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/learning-path` | GET | 学习路径概览 |
| `/api/learning-path/tree/:section` | GET | 科目技能树 |
| `/api/learning-path/trees` | GET | 所有科目技能树 |
| `/api/learning-path/templates` | GET | 路径模板 |
| `/api/learning-path/create` | POST | 创建自定义路径 |
| `/api/learning-path/recommend` | GET | 个性化推荐 |
| `/api/learning-path/update-progress` | POST | 更新进度 |
| `/api/learning-path/stats` | GET | 学习统计 |

**前端组件**：`LearningPath.vue`（技能树可视化+推荐学习+模板选择+技能详情弹窗）

### 3.3 🎯 Daily Micro-learning (每日碎片学习)

2. **每日词汇**：
   | 字段 | 说明 |
   |------|------|
   | word | 单词 |
   | phonetic | 音标 |
   | meaning | 释义 |
   | example | 例句 |
   | context | 语境 |
