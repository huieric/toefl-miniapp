## 一、项目概述

**托福备考助手**是一款面向托福考生的智能刷题工具。核心模式：用户导入PDF → AI解析题目 → 在线刷题 → 错题自动入库 → FSRS 科学排程复习。

### 1.1 技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端（Web） | Vue 3 + Vite + Element Plus | 响应式，PWA 支持，**深色模式** |
| 管理后台 | Vue 3 + ECharts + Element Plus | 数据看板 + 用户/题目管理 |
| 后端 | Node.js + Express + JWT | **27+ 路由模块**，RESTful API |
| 数据库 | PostgreSQL (端口5433) | **20+张表**，FSRS 17个参数 |
| AI能力 | DeepSeek/OpenAI兼容 | PDF解析、口语写作打分、阅读标注、错题分析 |
| 图表 | ECharts 5.6.0 | 错题本AI分析可视化 + 周报图表 + **技能雷达图** + **等级对比图** |
| 部署 | Vite build + 后端 dev | 前端已构建 dist/ 产物 |

## 三、v25.0 新增功能详细设计

### 3.1 🎉 Quizizz 即时反应系统

**竞品来源**：Quizizz（即时 meme 反馈 + 连击系统）

**核心功能**：
1. **5种情感反应**：
   | 情感 | Emoji | 动画 | 含义 |
   |------|-------|------|------|
   | 兴奋 | 🎉 | 彩纸 (confetti) | 答对且满意 |
   | 自豪 | 🏆 | 火焰 (fire) | 高分答对 |
   | 安心 | 😌 | 治愈 (heal) | 答对但勉强 |
   | 困惑 | 🤔 | 闪光 (sparkle) | 答错但不理解 |
   | 不甘 | 💪 | boost | 答错但想继续 |
2. **结果覆盖层动画**：答题后全屏弹出，带 scale + rotate 动画
3. **连击计数器**：连续答对显示 🔥N 徽章
4. **情感统计图**：进度条可视化 + 积极学习率计算

**数据库**：
- `quiz_reactions` 表：user_id, question_id, emotion, score, is_correct

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/quiz-reaction/record` | POST | 记录情感反应 |
| `/api/quiz-reaction/summary` | GET | 情感分析汇总 |
| `/api/quiz-reaction/streak` | GET | 连击统计 |

**前端组件**：`QuizReaction.vue` + Dashboard 入口卡片

### 3.2 🌐 CEFR 语言等级（Duolingo Language Level）

**竞品来源**：Duolingo CEFR 语言等级体系

**核心功能**：
1. **6级CEFR体系**：
   | 等级 | 名称 | 图标 | 所需XP |
   |------|------|------|--------|
   | A1 | 入门 | 🌱 | 0 |
   | A2 | 基础 | 🌿 | 300 |
   | B1 | 中级 | 🌳 | 800 |
   | B2 | 中高级 | 🏔️ | 1500 |
   | C1 | 高级 | ⭐ | 2500 |
   | C2 | 精通 | 👑 | 4000 |
2. **双维度评估**：基于总XP + 四科TOEFL分数
3. **四科CEFR细分**：每科独立CEFR等级
4. **升级进度追踪**：进度条 + 里程碑显示
5. **徽章墙**：展示解锁的成就

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/language-level` | GET | 获取语言等级和进度 |
| `/api/language-level/comparison` | GET | 获取四科对比数据 |

**前端组件**：`LanguageLevel.vue`（ECharts 雷达图对比）+ Dashboard 入口卡片

### 3.3 🎯 Todoist 式每日目标追踪

**竞品来源**：Todoist + 墨墨背单词

**核心功能**：
1. **6项目标设置**：
   | 目标 | 默认值 | 范围 |
   |------|--------|------|
   | 学习时间 | 30 分钟 | 10-300 |
   | 做题数量 | 20 题 | 1-100 |
   | 阅读篇数 | 5 篇 | 0-50 |
   | 听力篇数 | 5 篇 | 0-50 |
   | 口语次数 | 2 次 | 0-20 |
   | 写作篇数 | 2 篇 | 0-20 |
2. **环形进度图**：整体完成度可视化
3. **连续完成天数**：自动计算连续达标天数
4. **完成率统计**：历史完成率百分比
5. **目标自定义**：弹窗调整目标值
6. **历史记录**：最近30天完成情况

**数据库**：
- `daily_goals` 表：user_id, goal_date, study_minutes, target_questions, 分项目标, completed, completed_at

**API**：
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/daily-goals` | GET | 获取今日目标 + 进度 |
| `/api/daily-goals` | PUT | 更新目标 |
| `/api/daily-goals/history` | GET | 完成历史 |

**前端组件**：`DailyGoals.vue`（环形进度 + 卡片列表 + 历史网格）+ Dashboard 入口卡片
